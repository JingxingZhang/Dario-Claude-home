# 分镜方法（写分镜前必读；先做 visual-design.md 的视觉方案）

目标：观众看任何一秒，都能从画面上“读出”正在唱的那句词，还觉得好玩。做法是 **字面意思 + 综艺梗**：先把这句词里能画的人、物、动作画出来，再加一层综艺式的放大或吐槽。

## 1. 先读懂歌（写进“歌曲说明”）
- 谁对谁说？（“我”是谁、“你”是谁，还是在讲第三人）
- 一句话讲完这首歌：处境 → 选择 → 结局。
- 情绪曲线：哪句开始转折，副歌的情绪是什么。
- 段落时间：前奏、主歌、副歌、间奏、重复段、尾奏（看 lyrics.txt 的间隔和 audio.json 的音量）。

## 2. 定角色和贯穿物件（详见 visual-design.md）
- **主角从零设计**：人数、年龄、时代、穿着，甚至是不是人，都从歌词里找答案；用 `charkit.pixmap` 逐像素画，比例按曲风定。
  - 不要默认“一个女生 + 一个男生”。`chars.person` 那套 Q 版小人只用于试画和路人群演。
- **贯穿配角或物件，选一个用到底**：它是观众的“吐槽替身”或陪伴者，关键句都有反应（举牌、表情、拟声词）。
  - 宠物：猫、狗现成，或照 `props2.cat` 的写法新画一只兔子、鸟。
  - 代表物件：一把伞（下雨的歌）、一部旧手机（异地恋）、一杯奶茶（甜歌）、一只纸飞机（毕业）、一盏路灯（等人的歌）。用 `face()` 加表情就能演戏。
  - 它可以有成长线：开头睡着 → 中间吐槽 → 结尾陪主角走。
- **会演戏的物件**：优先让歌词里出现的东西演戏，在关键句做反应。
- 设定图 `CAST_SHEET` 和分镜一起交给用户确认。

## 3. 逐句设计：每句写满 5 格
| 格 | 问自己 |
|---|---|
| 场景 | 这句发生在哪？歌词提到地点就用；没提就选能放大这句情绪的地方（审讯室=逼问，天台=告白，片场=演戏，T 台=做自己） |
| 人物 | 谁在做什么动作、什么表情？把动词画出来（“挥着旗”就真挥旗，“缩着手”就真缩） |
| 像素花字 | 这句有没有声音（拟声词）、定性（印章）、心里话（OS）、系统感（弹窗、数值条、系统消息）？ |
| 配角/物件 | 贯穿配角怎么吐槽？哪个物件该有反应？ |
| 对应关系 | 用一句话说明为什么贴这句词；说不出来就重想 |

### 歌词意思 → 画面的转换手法
- **数量和时间**（“两天”“一整天”）→ 日历翻页、进度条狂飙、钟表、太阳移动。
- **抽象情绪**（“情绪决定”“心动”）→ 仪表、老虎机、开关、心电波形、BPM 数字。
- **真假、演戏**→ 测谎仪、面具掉落、片场打板“卡！”、评分牌。
- **离开、结束**→ 系统消息“对方已离开”、弹窗“确定离开吗？[是]”、背影越走越远、路灯变暗。
- **记住、在乎**→ 聊天气泡飞进心里、“已保存”、存档。
- **逼问、坦白**→ 审讯灯、清单一条条“叮”出来。
- **告白、喜欢**→ 喇叭喊话、整栋楼的窗户亮成心、烟花、捂脸“///”。
- **反转**→ 先给一个正常画面，再用通知、印章、弹窗“翻车”。

### 节奏
- 一句通常一个镜头。句子长于 5 秒就安排 2–3 个动作点（例如第 0.3 秒弹出、第 1.6 秒翻页、第 2.4 秒盖章），让画面一直在变。
- 动作点尽量踩在字上或拍上：重点词开唱的那一刻出印章或拟声词。
- 同一屏最多 3 处字：歌词花字 + 1–2 个像素字。太挤就删。

## 4. 结构规则
- **前奏**：0 秒就是标题卡（引擎叠加歌名和原唱），背后的画面要在动。之后用 2–3 个镜头交代：主角是谁、在哪、和贯穿配角的关系，最好埋一个后面会用到的道具。
- **间奏**：回忆戏（带标题的相片飘过）或情绪戏（雾上画心、看窗外）。贯穿配角在这里给温度。
- **重复段**：
  - 第二遍主歌：复用镜头，`v='replay'`（引擎自动加回放标签和褪色扫描线），再在 `DANMU` 里写弹幕吐槽；
  - 第二遍副歌：复用镜头，`v=True`，换第二套配色；
  - 全曲最后一句：可以改写结局（《呼吸决定》里这一次她收伞转身、盖章“清醒”）。
- **尾奏**：给一个情绪落点（雨停、天亮、彩虹、一起回家），贯穿配角收尾。
- **片尾**（`end_start` 起）：引擎显示歌名、原唱、“谢谢收看”；画面放一个安静的收尾，可以让配角举“谢谢收看”牌。

## 5. 自编内容
画面里的名字、聊天内容、梗（“小美：宝贝晚安”“同时约三个”）都是自编的，要在分镜表“自编梗”一节列出，请用户确认。不碰真人，不写低俗内容。

## 范例
`examples/huxi-jueding/`（mv.py + storyboard.md）：《呼吸决定》全片，38 句，四个段落的做法都有。那是中速 R&B 恋爱歌的一种做法：学方法（逐句 5 格、反转、物件演戏），不要照搬它的人物、场景和配色。
