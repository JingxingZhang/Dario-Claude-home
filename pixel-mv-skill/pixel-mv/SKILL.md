# pixel-mv · 像素综艺 MV

一首歌 → 一支像素综艺 MV。画面全部用代码绘制（不用 AI 生成图片），歌词逐句定制画面。

**风格（固定）**
- 画幅 16:9：原生 320×180 像素画，最近邻放大到 1920×1080，30 fps。
- 底部歌词是高清**综艺花字**：粗圆体、多层描边、渐变、逐字弹跳、重点词放大换色、贴纸。
- 画面里也“综艺”：像素拟声词、印章、内心 OS、系统消息、复古弹窗、数值条、开关、弹幕。
- 物件会演戏：月亮、路灯、垃圾桶、闹钟、手机、心、楼房……都有表情。
- 片头显示「歌名 + 原唱 · ×× + 像素 MV」，片尾再显示一次后淡出；底部居中常驻署名（默认 `@张景行`，在 `project.json` 改）。
- 成片 ≤ 100 MB。

**用户已确认的规则**
1. 只在**分镜做完后停一次**，等用户看过分镜再动手写画面；其余步骤一口气做完。
2. **主角按歌词定**（性别、年龄、人数、穿着都跟歌走）。贯穿全片的配角也按歌定：宠物（猫、狗……）或一件能代表整首歌的物件（伞、旧手机、一杯奶茶、纸飞机……）都可以。**场景按歌词定制**，不要套上一首歌的画面。
3. 只做 16:9 横屏。
4. 表情包没有固定模板：用户要的时候，再按这首歌的内容现做。
5. 成片不超过 100 MB。

设 `SK` 为本 skill 目录。新歌的工作目录放在 `/home/user/<仓库>/<歌名拼音>/`（或会话主工作目录下）。

## 流程

### 0 · 环境（每个新会话先跑，约 1 分钟）
`bash $SK/scripts/setup.sh`：检查 ffmpeg、装 Pillow/numpy/fontTools/brotli、下载三套 OFL 字体到 `~/.cache`。

### 1 · 收歌、认歌
- `ffprobe` 看时长和音视频流。
- 认歌名、原唱：先看文件名（上传时中文会变成 `_`，数一下字数也有帮助），再用 2–3 句有辨识度的歌词搜索，交叉核对。有翻唱时以首发 / 原唱为准，记下出处。认不出或来源互相矛盾 → 问用户。
- 新建项目：`python3 $SK/scripts/new_project.py <项目目录> --audio <歌曲文件> --title 歌名 --artist 原唱`

### 2 · 歌词与时间 → `tools/lyrics.txt`
每行 `开始秒 | 结束秒 | 歌词`，`/` 表示花字换行。按可用性选来源：
- **带硬字幕的歌词视频**：`python3 $SK/scripts/lyrics_ocr.py <视频> <项目>/tools/ocr`
  1. 先看 `band.png`，确认红框框住了字幕；不对就加 `--band 0.1,0.45`。
  2. 再用 Read 逐张看 `lines_*.png`，把读出的歌词填进 `lyrics_skeleton.txt` 的 `？？？`，另存为 `tools/lyrics.txt`。
  3. 结束时间可以放宽到下一句开始前 0.1 秒。
- **Suno 歌曲**：用 Suno 的 `audio-lyrics-alignment` 拿逐字时间，按行合并。
- **LRC 文件**：`python3 $SK/scripts/lrc2lyrics.py 歌词.lrc tools/lyrics.txt --dur 时长`
- **只有纯文本歌词**：按音量起伏和段落估时间，并告诉用户这些时间是估的。

### 3 · 音频分析 → `tools/audio.json`
`python3 $SK/scripts/audio_analyze.py <歌曲> <项目>/tools/audio.json`
产出逐帧音量、BPM、每拍时刻，供花字随鼓点跳、心跳和波形跟着动。

### 4 · 读懂歌、做分镜 → `分镜说明.md` ⏸ 停下给用户看
先读 `references/storyboard-guide.md`，再照 `分镜说明.md` 模板写：
- **歌曲说明**：谁对谁说、一句话讲这首歌、情绪转折、段落划分。
- **角色与贯穿物件**：主角外观；贯穿配角或物件及它在全片的戏路；会演戏的物件。
- **逐句分镜表**：场景｜人物动作和表情｜画面内像素花字｜配角和物件反应｜为什么贴这句。
- **结构规则**：
  - 前奏：标题卡 + 2–3 个交代镜头；
  - 间奏：回忆戏或情绪戏；
  - 重复段：第二遍主歌加「回放」和弹幕，第二遍副歌换配色，最后一句可以改写结局；
  - 尾奏：给一个情绪落点；
  - 片尾：卡片。
- **画面里自己编的梗**单独列出，请用户确认。

用 SendUserFile 发 `分镜说明.md`，在对话里用几句话概括亮点，**等用户确认或修改后再继续**。

### 5 · 写镜头 → `mv.py`
先读 `references/library-api.md`（素材库速查）和 `references/huazi-style.md`（花字规则）；拿不准写法时，看范例 `examples/huxi-jueding/mv.py`（《呼吸决定》全片）。
- `make_look()` 按分镜定制主角外观。贯穿配角：现成的有 `cat` / `dog`；物件可以用 `face()` 给任何形状加表情；没有的就照 `props2.py` 的写法在 `mv.py` 里画。
- 每个镜头写成 `fn(img, t, lt, v)`，动作按 `lt` 编排。`SHOTS` 用 `L(i)` 让镜头对齐第 i 句；重复段复用同一函数，`v` 传 `'replay'`（回放）或 `True`（第二套配色）。
- `CFG` 为每句定花字：配色、重点词、贴纸、位置。键可以直接用歌词原文，这样重复的句子自动共用一套样式。
- 场景都按这首歌现画，不要搬上一首歌的场景。

### 6 · 检查（循环到干净为止）
1. `python3 $SK/scripts/sweep.py <项目>`：全片扫一遍，必须 0 报错。
2. `python3 $SK/scripts/still.py <项目> /tmp/…/sheet.png 秒,秒,…`：导关键帧拼图，覆盖每句中段、每个动作点、片头、间奏、片尾。用 Read 逐张看，对照 `references/pitfalls.md` 的检查清单修。

修完再导一遍，直到看不出问题。

### 7 · 渲染（后台，2–5 分钟）
`python3 $SK/scripts/render.py <项目>`（`--from/--to --draft` 出小样）。
- 自动配原曲，体积 ≤ 100 MB；万一超了，会自动改两遍编码。
- 完成后从成片里抽 6 帧复看，确认时长与原曲一致。
- 长任务开工时告诉用户大概要多久。

### 8 · 交付
- **用 SendUserFile 发**：成片 MP4、16:9 封面（`still.py --full` 取最有戏的一帧）、`分镜说明.md`。
- **发布建议**：3–4 个抖音标题，每个说明选它的理由；首选把歌名放前面，加一个片中真实存在的钩子。简介写明「原唱：××｜像素二创 MV」；附话题和置顶评论的互动问题。
- **推送**：代码和文稿推送到仓库，成片、原曲音频不进仓库（`new_project` 生成的 `.gitignore` 已处理）。

### 附 · 互动表情包（用户要时才做）
内容按这首歌定制：用 MV 里的主角、贯穿配角和标志道具，配一个“操作”（点按钮、拉杆、盖章…）加前后两个状态。
- 照 `templates/sticker_template.py` 写，`Sticker(...).export()`；
- 产出 480×480 GIF（2.4 秒循环）和两张 1080×1080 静图（操作前 / 之后）；
- 表情包默认**不加署名**；
- 过去做过的三张在 `examples/stickers/`，只作参考。

## 底线
- 画面全部用代码绘制，不用 AI 生成图片，不模仿现成影视、动漫、游戏的具体画面或角色。
- 歌名和原唱要核实；简介注明原唱和二创，不写成或暗示是原唱官方作品。原曲和成片不进公开仓库。
- 画面里编的梗要标出来给用户确认；不编造与真人有关的负面事实。
- 歌词只用用户提供或从用户文件里读出的，不凭记忆补全整首歌词。
- 长任务放后台跑，并告诉用户大概要多久。

## 目录
- `scripts/`：
  - `setup.sh`、`fonts.py`：环境和字体；
  - `new_project.py`：新建项目；
  - `lyrics_ocr.py`、`lrc2lyrics.py`：歌词与时间；
  - `audio_analyze.py`：音频分析；
  - `sweep.py`、`still.py`：检查；
  - `render.py`：渲染。
- `lib/`：
  - `pixlib`：底层，像素字、抖动渐变、天空水面；
  - `chars`：人物 + 小道具；
  - `props2`：综艺元素、猫狗、会演戏的物件、场景道具；
  - `scenes_common`：霓虹街、雨、窗边室内；
  - `huazi`：高清花字；
  - `engine`：镜头表、歌词、片头片尾、回放、署名；
  - `sticker`：表情包。
- `templates/`：`mv_template.py`、`分镜说明模板.md`、`sticker_template.py`。
- `references/`：
  - `storyboard-guide.md`：分镜方法，必读；
  - `library-api.md`：素材库速查；
  - `huazi-style.md`：花字规则；
  - `pitfalls.md`：检查清单和踩过的坑。
- `examples/`：`huxi-jueding/`（《呼吸决定》全片镜头和分镜）、`stickers/`（三张表情包）。
