# pixel-mv · 为每首歌定制的像素 MV

**这个 skill 的目的**：根据一首歌的**曲风**和**歌词内容**，做一支只属于这首歌的像素风 MV。

- **要定制的**：人物、配角、场景、配色、节奏、花字动效，全部从这首歌里来。
- **不能套的**：没有默认主角，没有默认场景，也不沿用上一首歌的画面。
- **可以复用的**：素材库、脚本、范例只是工具和参考。

**不变的只有技术规格和署名约定**
- 16:9：原生 320×180 像素画，最近邻放大到 1920×1080，30 fps；画面全部用代码绘制，不用 AI 生成图片。
- 底部歌词是高清综艺花字。基调（回弹、逐字快慢、抖动）随曲风调整，重点词和配色随歌词选。
- 片头显示「歌名 + 原唱 · ×× + 像素 MV」，片尾再显示一次后淡出；底部居中常驻署名（`project.json` 的 `signature`，默认 `@张景行`）。
- 成片 ≤ 100 MB。

**用户已确认的规则**
1. 只在**分镜和角色设定做完后停一次**，等用户确认再画；其余步骤一口气做完。
2. **主角、配角、场景都按歌词定制**。
   - 主角：人数、年龄、时代、穿着、比例，甚至是不是人，都由歌词决定。
   - 贯穿配角：宠物或一件代表物件，选最贴这首歌的。
3. 只做 16:9。
4. 表情包没有固定模板，用户要的时候按这首歌现做。
5. 成片不超过 100 MB。

设 `SK` 为本 skill 目录。

## 流程

### 0 · 环境（每个新会话先跑，约 1 分钟）
`bash $SK/scripts/setup.sh`：检查 ffmpeg 和 Python 依赖，下载三套 OFL 字体（像素字、花字黄油体、快乐体）。

### 1 · 收歌、认歌
- `ffprobe` 看时长和音视频流。
- **认歌名、原唱**：
  - 先看文件名。上传时中文会变成 `_`，数一下字数也有帮助。
  - 再用 2–3 句有辨识度的歌词搜索，交叉核对。
  - 有翻唱时以首发 / 原唱为准，记下出处。
  - 认不出或来源矛盾 → 问用户。
- **顺便查曲风**：流派、编曲特点，供第 4 步使用。
- **新建项目**：`python3 $SK/scripts/new_project.py <项目目录> --audio <歌曲> --title 歌名 --artist 原唱`

### 2 · 歌词与时间 → `tools/lyrics.txt`
每行 `开始秒 | 结束秒 | 歌词`，`/` 表示花字换行。
- **带硬字幕的歌词视频**：
  1. 跑 `python3 $SK/scripts/lyrics_ocr.py <视频> <项目>/tools/ocr`。
  2. 先看 `band.png`，确认红框框住了字幕；不对就加 `--band 0.1,0.45`。
  3. 用 Read 看 `lines_*.png`，把读出的歌词填进 `lyrics_skeleton.txt`，另存为 `lyrics.txt`。
- **Suno 歌曲**：用 `audio-lyrics-alignment` 拿逐字时间，按行合并。
- **LRC 文件**：`python3 $SK/scripts/lrc2lyrics.py 歌词.lrc tools/lyrics.txt --dur 时长`
- **只有纯文本**：按音量和段落估时间，并告诉用户这些时间是估的。

### 3 · 音频分析 → `tools/audio.json`
`python3 $SK/scripts/audio_analyze.py <歌曲> <项目>/tools/audio.json`：逐帧音量、BPM、每拍时刻。

### 4 · 视觉方案 + 角色设计 + 分镜 ⏸ 停下给用户看
依次读 `references/visual-design.md`（曲风 → 视觉）和 `references/storyboard-guide.md`（逐句分镜），然后做三件事：

1. **视觉方案**，写进 `分镜说明.md` 开头：
   - 曲风判断：流派、BPM、能量起伏，决定剪辑节奏、动作幅度、花字基调；
   - 世界：时代、地点、季节、天气，取自哪些歌词；
   - 配色：主色、强调色、暗色和理由，第二遍副歌怎么变；
   - 角色比例和理由。
2. **角色设计**：在 `mv.py` 里用 `charkit.pixmap` 字符画从零画。
   - 要画的：主角；贯穿配角或物件；会演戏的物件。
   - 每个角色至少画：站立、一个最关键的动作，加 4–6 种表情。
   - 写 `CAST_SHEET(img, t)`，用 `python3 $SK/scripts/cast_sheet.py <项目> <项目>/cover/角色设定.png --gif` 导出设定图。
3. **逐句分镜表**：
   - 每句写 5 格：场景｜人物动作和表情｜画面内像素字｜配角和物件反应｜为什么贴这句。
   - 另写前奏、间奏、重复段（回放 + 弹幕，第二遍换色，最后一句可以改结局）、尾奏、片尾的安排。
   - 自编的梗单独列出。

用 SendUserFile 发 `分镜说明.md` 和 `角色设定.png / .gif`，在对话里概括视觉方案和亮点。**等用户确认或修改后再继续。**

### 5 · 写镜头 → `mv.py`
- **先读的资料**：`references/library-api.md`（工具速查）、`references/huazi-style.md`（花字规则）；拿不准写法时，看 `examples/huxi-jueding/mv.py` 怎么组织代码，但不照搬画面。
- **镜头写法**：
  - 每个镜头写成 `fn(img, t, lt, v)`，动作按 `lt` 编排，节奏按视觉方案来：抒情少切慢动，快歌多动作点、踩拍。
  - 场景按世界观现画，可以用 `dither_grad`、`draw_sky`、`draw_water`、`props2` 的道具；`scenes_common` 的霓虹街、窗边只在歌词真的需要时才用。
- **镜头表 `SHOTS`**：用 `L(i)` 对齐第 i 句；重复段复用同一函数，`v` 传 `'replay'` 或 `True`。
- **花字配置**：`LYRIC_BASE` 写曲风基调，`TITLE_STYLE` 写片头歌名样式，`CFG` 为每句选配色、重点词、贴纸；`CFG` 的键可以直接用歌词原文。

### 6 · 检查（循环到干净为止）
1. `python3 $SK/scripts/sweep.py <项目>`：全片扫错，必须 0 报错。
2. `python3 $SK/scripts/still.py <项目> <拼图.png> 秒,秒,…`：导关键帧拼图，覆盖每句中段、动作点、片头、间奏、片尾。用 Read 逐张看，对照 `references/pitfalls.md`。

第 0 条最重要：这些画面换到别的歌上也说得通吗？说得通就是还在套模板，要重做。

### 7 · 渲染（后台，2–5 分钟）
`python3 $SK/scripts/render.py <项目>`（`--from/--to --draft` 出小样）。
- 自动配原曲，体积 ≤ 100 MB，超了会自动改两遍编码。
- 完成后从成片里抽 6 帧复看，确认时长一致。
- 开工时告诉用户大概要多久。

### 8 · 交付
- **用 SendUserFile 发**：成片 MP4、16:9 封面（用 `still.py --full` 取最有戏的一帧）、`分镜说明.md`、角色设定图。
- **发布建议**：
  - 3–4 个抖音标题，每个说明理由；首选歌名在前，加一个片中真实存在的钩子；
  - 简介写明「原唱：××｜像素二创 MV」；
  - 话题；置顶评论的互动问题。
- **推送**：代码和文稿推送到仓库，成片和原曲不进仓库。

### 附 · 互动表情包（用户要时才做）
1:1，内容按这首歌定制：用 MV 里的角色、贯穿配角和标志道具，配一个“操作”和前后两个状态。
- 写法：`templates/sticker_template.py` + `lib/sticker.py`，最后 `Sticker(...).export()`。
- 产出：480×480 GIF（2.4 秒循环）+ 两张 1080×1080 静图。
- 默认不加署名。
- `examples/stickers/` 只作参考。

## 底线
- 画面全部用代码绘制，不用 AI 生成图片，不模仿现成影视、动漫、游戏的具体画面或角色。
- 歌名、原唱要核实；简介注明原唱和二创，不写成或暗示是官方作品。成片和原曲不进公开仓库。
- 画面里编的梗要标出来给用户确认；不碰真人负面信息。
- 歌词只用用户提供或从用户文件里读出的，不凭记忆补全。
- 长任务放后台跑，并告诉用户大概要多久。

## 目录
- `scripts/`：
  - `setup.sh`、`fonts.py`：环境和字体；
  - `new_project.py`：新建项目；
  - `lyrics_ocr.py`、`lrc2lyrics.py`：歌词与时间；
  - `audio_analyze.py`：音频分析；
  - `cast_sheet.py`：角色设定图；
  - `sweep.py`、`still.py`：检查；
  - `render.py`：渲染。
- `lib/`：
  - `charkit`：角色设计，字符画精灵、眼睛、嘴、配色条；
  - `pixlib`：底层，像素字、抖动渐变、天空水面；
  - `props2`：综艺元素、会演戏的物件、宠物、场景道具；
  - `chars`：小道具、背景特效，以及 Q 版小人脚手架；
  - `scenes_common`：霓虹街、雨、窗边；
  - `huazi`：花字；
  - `engine`：镜头表、歌词、片头片尾、回放、署名；
  - `sticker`：表情包。
- `templates/`：`mv_template.py`（只有骨架，没有默认角色）、`storyboard_template.md`（分镜说明模板）、`sticker_template.py`。
- `references/`：
  - `visual-design.md`：曲风 → 视觉，必读；
  - `storyboard-guide.md`：逐句分镜，必读；
  - `library-api.md`：工具速查；
  - `huazi-style.md`：花字规则；
  - `pitfalls.md`：检查清单。
- `examples/`：`huxi-jueding/`（《呼吸决定》，中速 R&B 恋爱歌的一种做法，只作参考）、`stickers/`。
