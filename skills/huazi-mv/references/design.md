# 视觉方案怎么定（第 4 步）

综艺花字版的画面里没有人物。故事靠三条随时间变化的曲线来讲：**配色**、**天气**、**母题**，再加每句歌词的动效和标签。先把这几样定下来，再写 `config.py`。

## 1. 先读歌，再定故事
1. **查背景**：作词、作曲、专辑、发行年份，有没有官方说明或访谈；没有官方说法时，写清楚是“听众/媒体解读”还是“我的理解”。用 2–3 组关键词搜索，记下来源和日期。
2. **通读歌词**：谁对谁说；情绪从哪里起、在哪句转折、落在哪里；哪些句子重复、重复时语境有什么变化。
3. **一句话故事**：用画面讲得出的一句话，比如《晴天》是“一场雨，从回忆一直下到现在；等到放晴那天，你已经不在”。故事只能放大歌词里已有的意思，不能新造坏人、背叛、误会。

## 2. 段落和章节
用歌词间的空档和 `audio.json` 的低频 / 高频能量划段落：前奏、主歌、副歌、间奏、主歌二、副歌二、桥段、尾奏。每段一个章节名（`CHAPTERS`），比如「序 / 回忆 / 雨 / 雨后 / 午后 / 暴雨 / 晴天 / 尾声」。章节名就是故事的提纲。

## 3. 配色剧本
- 每段一个画面配色（`PAL_KEYS`）和一个花字配色（`SCHEMES`），跟着故事走：回忆用暖色，低落用冷色和暗色，高潮用最亮、最饱和的一套。
- 相邻两段之间留 2–4 秒过渡，过渡点放在段落交界或某句关键歌词上。
- 全片只留**一个**最高饱和的强调色给母题（《晴天》是小黄花的黄），让它一出现就被看见。

## 4. 天气曲线
天气是情绪的放大器，按歌词里的意象来：
- 歌词有雨、风、雪、晴、星、海时，直接用；没有时，用天气表达情绪强弱（副歌加风、高潮放晴）。
- **第一遍和第二遍的天气要不一样**：第一遍铺垫，第二遍兑现（《晴天》第一遍副歌只有云缝透光，第二遍真的放晴）。
- 高潮那一刻配 `FLASHES` 闪白，或 `LIGHTNING` 闪电。

## 5. 母题
选一个能代表这首歌的小东西，写成 `scene()`：花、伞、纸飞机、星星、猫、灯、信封……给它一条成长线：出现 → 变化（被雨打、丢失、飞走）→ 结局（重新开、回来、放手）。母题出现的时刻踩在相关歌词上。

## 6. 逐句动效和重点词
- 每句先问“这句话里有什么动作或意象”，再从 `config.md` 第 3 节的表里挑样式；没有特别动作的句子用 `center`，不要每句都用花样，节奏会乱。
- 每句 0–2 个重点词（`acc`）：动词、情绪词、意象词、反转词。
- 花字不会自动换行：一句超过 11 个字时，用 `size` 调小到 92–100，并在预览里确认没有出画面。

## 7. 综艺标签
- 标签是“吐槽 / 点题”，2–6 个字：「回忆开始」「童年回忆杀」「逃课警告」「灵魂拷问」「看不见了…」「+1天」「意难平」「晴天来了！」。
- 只放大歌词里已有的情绪，不编人名、不编剧情、不碰真人。
- 重复段换呼应说法（「二刷回忆」「又翘课」「风更大了」）。
- 标签全是自编的，交付时列给用户确认。

## 8. 曲风对应的节奏
| 曲风 | 镜头感 | 建议 |
|---|---|---|
| 慢板抒情（< 80 BPM） | 慢、留白多 | 少用 `rainheavy` / `clear` 这类重动效；天气缓慢变化；标签少一点 |
| 中速流行（80–110） | 默认 | 副歌开 `CHORUS` 踩拍；标签正常密度 |
| 快歌、舞曲（> 110） | 密 | 多用 `rainheavy`（砸下）、`wind`、`spread`；`CHORUS` 覆盖整段副歌；可加 `LIGHTNING` 当鼓点闪光 |
| 说唱 | 跟词 | 每句都短，`center` 为主；重点词多；标签可以更密 |
