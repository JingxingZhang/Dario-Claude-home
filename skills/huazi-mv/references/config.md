# config.py 字段说明

每首歌一个项目目录：`config.py`（本文件描述的字段）+ `audio.json`（`analyze_audio.py` 生成）。
引擎读 `config.py` 里的大写变量；只有 `TITLE` 和 `LINES` 必填，其余都有默认值。完整示例见 `examples/qingtian/config.py`。

时间一律是**秒**，以成片音频为准（换音源后要用 `align_lines.py` 重新对齐）。

## 目录
1. 基本信息
2. LINES：每句歌词
3. 动效样式（style）一览
4. 段落配色：PAL_KEYS、SCHEMES、KW
5. 天气曲线
6. 标签、贴纸、无歌词段落
7. 母题钩子 scene()
8. 片头片尾、封面

---

## 1. 基本信息
| 字段 | 说明 | 例 |
|---|---|---|
| `TITLE` | 歌名（片头、片尾、左上角、封面） | `'晴天'` |
| `ARTIST` | 原唱（片头片尾的标签） | `'周杰伦'` |
| `ARTIST_LATIN` | 左上角歌名旁的英文名，可省略 | `'Jay Chou'` |
| `TITLE_SUB` | 片头歌名下的一行小字（英文斜体） | `'Sunny Day · 2003'` |
| `TITLE_IN` / `TITLE_OUT` | 片头歌名第一个字出现 / 开始退场的时间，默认 2.0 / 12.6 | |
| `HUD_FROM` | 左上角歌名、右上角章节、底部进度条出现的时间，默认 15.3 | |
| `END_START` | 片尾卡开始的时间（一般是最后一句唱完、尾奏后半） | `256.0` |
| `TOTAL` | 成片总时长，默认 = 音频时长 + 2.5 秒（最后 1.4 秒淡出到黑） | `272.0` |
| `CHAPTERS` | 右上角章节：`[(开始秒, '英文/编号', '中文名'), …]` | `[(0, 'Prelude', '序'), (29.2, 'I', '回忆')]` |

## 2. LINES：每句歌词
`LINES` 是按时间排序的列表，每句一个 dict：

| 键 | 必填 | 说明 |
|---|---|---|
| `t0`, `t1` | 是 | 开唱、唱完的时间 |
| `text` | 是 | 歌词原文（来自用户提供的文件，不凭记忆补） |
| `style` | 是 | 动效样式，见第 3 节 |
| `sec` | 是 | `'v'` 主歌（站酷快乐体 104 号）或 `'c'` 副歌（思源黑体 Black 104 号） |
| `acc` | | 重点词列表，如 `['放晴']`；配色由 `KW` 决定，放大 14% 并脉动 |
| `y` | | 这句的中心高度（1080p 坐标），默认 540 |
| `hold` | | 唱完后停留多久再退场，默认 1.0 |
| `keep` | | `True` = 不因下一句开始而提前退场（竖排两列同时显示时用） |
| `seg` | | 逐字出现时间分段：`[(字数, 开始, 结束), …]`，用于一句里有明显停顿 |
| `col` | | `vert` 样式的列中心 x（右列先唱：如 1130，左列 990） |
| `seal` | | `vert` 样式列末盖一枚印章，字由 `SEAL_CHAR` 决定（默认歌名第一个字） |
| `icon` | | `'sun'` = 句末出现笑脸太阳贴纸 |
| `font`, `size`, `track` | | 覆盖字体（`'kl'` 快乐体、`'sb'` 黑体 Black、`'s6'` 宋体）、字号、字距 |

逐字出现的间隔是估算的：`min(时长 × 0.72, 字数 × 0.34 秒) ÷ 字数`。有逐字时间时用 `seg` 拆细。

## 3. 动效样式一览
按“这句话在说什么动作”来选：

| style | 画面 | 适合 |
|---|---|---|
| `center` | 普通逐字弹跳入场 | 默认，大多数句子 |
| `bloom` | 字在下方，上方是 `scene()` 画的母题（如开花） | 第一句、点题句 |
| `float` | 整句缓慢上飘、轻微波动 | 飘、想念、回忆起 |
| `swing` | 字坐在秋千板上摆动（配 `SWINGS`） | 荡、晃、摇 |
| `sky` | 字放在画面上方 | 望着天空、星星、月亮 |
| `fall` | 字出全后一个个像花瓣旋转掉落 | 掉落、凋谢、眼泪 |
| `vert` | 竖排，右起，配 `col`、`keep`、`seal` | 古风、书信、回忆里的场景 |
| `window` | 画出窗格，字在窗里，最后起雾变模糊 | 看不见、隔着、教室、车窗 |
| `question` | 两个选项一个往上、一个往下分开，中间的连接词变淡，配问号贴纸。用行里的 `up` / `down` / `dim` 指定字的序号（从 0 数），默认 (2,3) / (6,7) / (4,5)，对应「你会**等待**还是**离开**」 | 二选一的问句 |
| `wind` | 字被风吹斜，左侧速度线（配 `WIND_K`） | 风 |
| `rainheavy` | 每个字像雨滴砸下再回弹，旁边雨滴贴纸 | 雨大、情绪爆发 |
| `blurout` | 字出全后被雨打模糊、变淡 | 看不清、消失、遗忘 |
| `distance` | 底部两个小点（我、你），我靠近但到不了 | 距离、等待、多久 |
| `storybook` | 两侧展开细线和菱形装饰 | 从前、故事、童话 |
| `spread` | 字间距慢慢拉开到画面两侧 | 越来越远、分开 |
| `drift` | 字从后往前一个个被风吹走 | 再见、离开、最后一句 |
| `clear` | 字从大砸下，常配 `FLASHES` 全屏闪白 | 全片高潮、转折 |

另外两种不是 style，用单独字段：唱名 / 哼唱用 `SOLFEGE`（五线谱），无歌词段落用 `BADGES`。

**重复段**：同一句歌词第二遍出现时，至少换一样东西（样式、重点词、标签说法），并靠段落配色和天气区分。

## 4. 段落配色
**画面背景** `PAL_KEYS`：`[(秒, 配色名), …]`，相邻两项之间平滑过渡。内置配色：

| 名 | 感觉 | 名 | 感觉 |
|---|---|---|---|
| `paper` | 米白纸面，片头 | `dusk` | 黄昏金 |
| `memory` | 暖棕旧纸，回忆 | `night` | 深夜 |
| `mist` | 雨雾灰 | `clear` | 晴空蓝 |
| `storm` | 深青暴雨 | `after` | 雨后雾灰 |

自定义：`EXTRA_PALETTES = {'sakura': ('#F6D6E0', '#FFF1F4', '#5A2A3A', '#E85A8A')}`（天顶、地平线、文字色、强调色）。

**花字配色** `SCHEMES`：`[(秒, 配色名), …]`，每句按开唱时间取当时的配色。内置：`memory` 暖黄棕边、`mist` 白蓝、`storm` 冰蓝光晕、`dusk` 奶白橙、`night` 白紫光晕、`clear` 白黄蓝边。
自定义：`EXTRA_SCHEMES = {'pink': ('#FFFFFF', '#FFB3CF', '#B0245A', '#3D0A1E')}`（填充上、填充下、外描边、投影）。

**重点词** `KW`：`{'词': '配色名'}`。内置重点词配色：`kw_flower` 金黄、`kw_rain` 雨蓝、`kw_sun` 放晴橙、`kw_love` 爱心粉、`kw_bye` 淡紫、`kw_wind` 风青。带 `kw_love` 的句子会自动飘爱心。

## 5. 天气曲线
都是 `[(秒, 值), …]` 关键帧，值 0–1，平滑插值：

| 字段 | 效果 |
|---|---|
| `RAIN_K` | 雨量（前后两层雨线） |
| `WIND_K` | 风力（雨线倾斜、云移动速度、`wind` 样式的倾斜度） |
| `SUN_K` | 暖光强度；`SUN_DISC_FROM` 之后还会画太阳和光束 |
| `CLOUD_K` | 云量 |
| `GLASS_K` | 镜头前的玻璃水珠 |

其他：`LIGHTNING = [秒, …]` 闪电；`FLASHES = [秒, …]` 全屏闪白（放晴、高潮）；`CHORUS = [(开始, 结束), …]` 副歌区间，区间内花字和画面踩主拍轻微放大。
`PETAL_EMIT = [(开始, 结束, 每秒数量, 区域, 模式), …]`：花瓣粒子。区域 `'top'`（从上方落）/ `'left'`（从左边飘）/ `'field'`（从底部花田吹起）/ `'flower'`（从画面中央的花落）；模式 `'fall'` / `'drift'` / `'blow'`。

## 6. 标签、贴纸、无歌词段落
- `TAGS = {句序号: '标签文字'}`：句末右上角弹出的综艺小标签（序号从 0 数，按 `LINES` 顺序）。2–6 个字最好，说出这一句的“梗”：「童年回忆杀」「灵魂拷问」「意难平」「+1天」。重复段换呼应的说法：「又翘课」「风更大了」。不是每句都要有，全片 20–30 个比较合适。
- 贴纸自动出现：重点词旁星星；`question` 问号；`kw_love` 爱心；`rainheavy` / `blurout` 雨滴；`wind` 速度线；`icon='sun'` 太阳。
- `BADGES = [dict(t0=, t1=, text='吉他 Solo', scheme='kw_sun', notes=True)]`：间奏、solo 这类没有歌词的段落中间的大标签，`notes=True` 时音符踩主拍飘起。
- `SOLFEGE = [(开始, 结束, [(t0, t1, 'Re So So Si', [6, 2, 2, 4]), …])]`：五线谱上逐个弹出音符和唱名。音高步数以最下面一条线 E4 为 0，向上每个线或间 +1。
- `SWINGS = [(开始, 结束)]`：`swing` 样式的摆动时间段；`SWING_PERIOD` 摆动周期，默认 1.764 秒（约两个主拍）。

## 7. 母题钩子 scene()
每首歌最好有一个贯穿全片的小母题（花、纸飞机、星星、猫、伞……），跟着故事变化。写在 `config.py` 里：

```python
def scene(c, t, pal, ctx, E):
    # c：skia 画布（1920×1080）；t：秒；pal：(天顶色, 地平线色, 文字色, 强调色)；ctx['wind']：当前风力
    # E：引擎模块，可用 E.draw_flower、E.field_flowers、E.ripples、E.beat_notes、E.paint、E.pulse、E.BEATS、
    #    缓动 E.eo3 / E.eio / E.eback / E.smooth、插值 E.lerp / E.mixc、颜色 E.hx('#RRGGBB')
    if 29 < t < 37:
        E.draw_flower(c, 960, 400, 1.6, E.eo3((t - 29.2) / 1.4), E.FLOWER_COL, E.FLOWER_CEN, 1)
```

`scene()` 画在歌词下面、远层雨线上面；需要盖在歌词上面的写 `scene_over()`。
没有现成画法的母题，用 skia 的 Path、圆、矩形自己画，保持扁平、圆润、带白边，和花字风格一致。

## 8. 片头片尾、封面
- `TITLE_SCHEME`（片头歌名配色，默认 `memory`）、`END_SCHEME`（片尾，默认 `clear`）、`END_SUB`（片尾小字）、`END_ICON='sun'`。
- `COVER = dict(palette='clear', scheme='clear', line='高潮那句歌词', kw=['重点词'], kw_scheme='kw_sun', flowers=True, icon='sun', label='综艺花字 MV')`，给 `make_cover.py` 用。
