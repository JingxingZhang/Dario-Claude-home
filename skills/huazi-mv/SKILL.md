# 综艺花字 MV

把一首歌做成一支 1080p、30fps 的综艺花字歌词 MV。画面全部由代码绘制（skia），不用视频生成模型、不用素材。

- **花字**：每个字五层叠加（硬投影、深色外描边、白色内描边、竖向渐变、高光），逐字回弹入场，副歌踩拍放大，重点词变色，加星星、问号、爱心、雨滴、太阳这类贴纸，句末弹出综艺小标签。
- **故事**：画面里不画人物，用三条随时间变化的曲线讲故事：配色、天气、母题（比如一朵贯穿全片的小黄花）。
- **交付**：1080p 原画，不为体积压缩；通过私密下载页交付（对话里直接发大文件，用户经常下载不了）。

设 `SK` 为本 skill 目录，`P` 为这首歌的项目目录（建议放在 scratchpad，例如 `<scratchpad>/<歌名>-huazi/`）。

## 需要用户提供什么
| 必需 | 说明 |
|---|---|
| 音源 | 无损（FLAC / WAV / ALAC）最好；mp3、m4a 也能做 |
| 歌词 | 三选一，效果从好到差：**LRC 时间戳歌词** ＞ **带硬字幕的歌词视频** ＞ **纯文本歌词**（时间只能估，要告诉用户） |

**歌词只用用户提供的文件，不凭记忆默写或补全**：一是记忆会错，二是整首歌词涉及版权。用户只给了音源时，先请他补歌词（建议 LRC），再开工。
流媒体 App 的离线下载文件（.ncm、.qmc、带 DRM 的 m4a）是加密的，用不了，也不要去解密；请用户换成正规渠道导出或购买的未加密文件。

## 流程
整首歌大约 2 小时，其中整片渲染约 15–25 分钟。只在第 5 步停一次，等用户确认风格；其余一口气做完，每完成一步用一句话告诉用户进度。

### 0 · 环境（每个新会话先跑）
```bash
bash $SK/scripts/setup.sh
```
装 skia-python、librosa、opencv，补系统图形库，下载五套开源字体到 `~/.cache/huazi-mv/fonts`。

### 1 · 收素材、认歌、验音质
```bash
python3 $SK/scripts/probe_audio.py <音源>
```
- 看格式、时长、标签（歌名、歌手、专辑）。上传后中文文件名常变成下划线，以标签为准；没有标签就用 2–3 句歌词搜索核对，认不出就问用户。
- **验真无损**：脚本按频谱判断。高频平滑衰减到 21 kHz 以上 = 真无损；16–20 kHz 处陡降 = 有损转码。结论告诉用户。
- 用户问“黑胶品质 / Hi-Res”时，同样用这个脚本验；高解析度在 mp4 里要保留，就用第 7 步的 `--audio alac`。

### 2 · 歌词时间轴 → `$P/lines.json`
按用户给的歌词形式选一种：
- **LRC**：`python3 $SK/scripts/lrc_to_lines.py 歌词.lrc $P/lines.json`。LRC 常有零点几秒的整体偏移，在第 5 步预览时核对第一句的花字是不是和开唱同步。
- **歌词视频**：
  1. `python3 $SK/scripts/sub_detect.py 视频.mp4 $P/subs`，先看 `band.png` 确认红框框住了字幕，不对就加 `--band 0.70,0.86`。
  2. 用 Read 看 `sheet_*.png`，逐段读出文字，和 `segments.json` 的时间合并成 `lines.json`（`[{t0, t1, text}]`）。
  3. 修正字幕错字；字幕切分和演唱不一致的地方合并或拆开，有明显停顿的句子用 `seg` 写逐字时间。
  4. 视频音轨和要用的音源不是同一个文件时（例如视频是抖音版，音源是无损原版），再对齐一次：`python3 $SK/scripts/align_lines.py 视频.mp4 音源.flac $P/lines.json $P/lines_aligned.json`。看输出：置信度 < 0.95 或“时间倒退”的句子说明两个音源结构不同（剪辑版、拼接版很常见），按目标音源的真实结构重排，缺的段落（间奏、solo、最后一遍副歌）要补画面。
- **纯文本**：按 `audio.json` 的能量起伏和段落空档估时间，在交付时明确告诉用户哪些是估的。

### 3 · 音频分析 → `$P/audio.json`
```bash
python3 $SK/scripts/analyze_audio.py <音源> $P/audio.json
```
得到时长、速度、主拍（慢歌常被测成两倍速，脚本会自动取一半）和每帧的低 / 中 / 高频能量。段落划分看低频和高频能量的变化，再加上歌词之间的空档。

### 4 · 视觉方案
先读 `references/design.md`。按顺序定下：
1. 创作背景（搜索，记来源和日期；没有官方说法就注明是解读）。
2. 一句话故事。
3. 段落和章节名。
4. 配色剧本（画面 + 花字）。
5. 天气曲线。
6. 贯穿母题和它的成长线。
7. 每句的动效样式、重点词、综艺标签。

然后写 `$P/config.py`，字段见 `references/config.md`，完整写法参考 `examples/qingtian/config.py`。母题写成 `scene()` 函数。

### 5 · 预览，请用户确认风格 ⏸
```bash
python3 $SK/scripts/contact_sheet.py $P $P/preview_1.jpg 6,30,45,60,85,95,110,150,205,240
```
- 时间点覆盖片头、每段第一句、高潮、间奏、片尾，一次 9–15 张。用 Read 逐张看，对照 `references/pitfalls.md` 的检查清单，有问题就改 `config.py` 再出一张，直到干净。
- 把一张最能代表风格的对照图发给用户，说明故事、配色走向、母题和自编的标签，**等用户确认后再整片渲染**（整片渲染一次 15–25 分钟，返工代价大）。

### 6 · 整片渲染
```bash
python3 $SK/scripts/render_all.py $P <音源> $P/<歌名>_综艺花字版_1080p.mp4 --workers 4 --crf 22
```
- 后台运行，并告诉用户大概要多久。
- 音频默认 AAC 320 kbps，兼容性最好。用户要保留无损就加 `--audio alac`，或两个版本都给。
- 音源结尾是硬切的，加 `--fade-out 1`。
- 完成后从成片里抽 12–18 帧拼图复看（`ffmpeg -ss <秒> -i 成片 -frames:v 1`），并确认成片时长和音频一致。

### 7 · 封面
```bash
python3 $SK/scripts/make_cover.py $P $P/封面_3x4.png
```
1080×1440 竖版：歌名大花字 + `COVER['line']`（高潮那句）+ 原唱标签 + 母题背景。Read 看一遍再发。

### 8 · 交付：私密下载页
成片通常 100–200 MB，对话里直接发容易下载不了，所以用下载页：
1. `python3 $SK/scripts/split_upload.py 成片.mp4 $P/upload --prefix v1`：切成 ≤19 MB 的块，并校验拼回去和原片逐字节一致。
2. 用 Artifact 工具发布一个页面，声明 capabilities `{"assets": {}, "downloads": true}`；把所有块和封面 jpg 用 `asset: true` 上传到这个页面，记下每个 `/_blob/…` 地址。
3. 写 `page.json`（格式见 `scripts/build_page.py` 顶部说明），`python3 $SK/scripts/build_page.py $P/page.html $P/page.json`，再发布到同一个页面。
4. 用户之前已经有下载页时，把新版本加到 `versions` 最前面，旧版本保留，链接不变。

页面上每个版本都有「载入并播放」和「下载 1080p」：浏览器先拼回完整文件，再弹出保存确认。告诉用户在 claude.ai 网页或 Claude App 里打开，手机建议连 Wi-Fi。

### 9 · 收尾
- 封面用 SendUserFile 发给用户；下载页给链接。
- 列出**需要用户确认的地方**：自编的标签、有歧义的歌词读法、置信度低或推算出来的时间。
- 代码推仓库前先看仓库是不是公开的：公开的话，歌词（`lines.json`、`config.py`）、音频、字体、成片都不提交。
- 提醒用户：公开发布要注明原唱和“二创”，音乐授权以平台规则为准。

## 目录
- `scripts/`
  - `setup.sh`：环境和字体
  - `probe_audio.py`：音源信息与真无损判断
  - `sub_detect.py`：从歌词视频提取字幕段和对照图
  - `lrc_to_lines.py`：LRC 转 lines.json
  - `align_lines.py`：把时间轴从一个音源迁移到另一个音源
  - `analyze_audio.py`：节拍、主拍、频段能量
  - `engine.py`：渲染引擎（预览单帧、分段出帧）
  - `huazi.py`：花字和贴纸
  - `contact_sheet.py`：预览对照图
  - `render_all.py`：整片并行渲染 + 配音频
  - `make_cover.py`：3:4 封面
  - `split_upload.py`：切块与校验
  - `build_page.py`：生成下载页
- `assets/download_page.html`：下载页模板（浏览器内拼合 + 保存确认）。
- `references/`
  - `config.md`：config.py 全部字段、17 种动效样式、配色名，写配置时读
  - `design.md`：怎么从歌词定故事、配色、天气、母题、标签，第 4 步前读
  - `pitfalls.md`：预览检查清单和常见问题，第 5–8 步读
- `examples/qingtian/config.py`：周杰伦《晴天》的配置（只保留了 12 句歌词作写法示例），含小黄花母题的 `scene()`。
