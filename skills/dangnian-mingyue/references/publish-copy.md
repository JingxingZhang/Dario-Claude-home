# 发布文案（每集交付一份 `发布文案.md`）

成片发在抖音。标题和封面让人点进来，简介和话题让系统知道推给谁，置顶评论把讨论带起来。文案和歌词用**同一种声音**：具体的人、物、数，冷静，悬着，不喊。所有说法都要和史实核对表一致。

## 模板

```markdown
# 发布文案 · 大明开局 · 第10集《江水在涨》

## 标题（3 选 1，≤ 30 字：一个具体的人或物 + 一个悬着的事实）
1. 1363年，他没听那八个字
2. 江水在涨，下游有人在磨桨
3. 城里坐着一个名义上的皇帝

## 封面大字（两行，每行 ≤ 7 字；与 cover.html 的 COVER.hook 一致）
一封劝谏
江水在涨

## 简介（100–200 字）
1363年，安丰被围。一个穿长衫的人只说了八个字：汉吴伺隙，未可动也。他点点头，然后跨上了马。
下游，有人号称六十万，正顺流而下。
结尾有一张图，看懂这一集。
参考：《明史·太祖本纪》《明史·刘基传》；讲法参考《明朝那些事儿》。

## 话题（5–8 个：1–2 个大话题 + 2–3 个中话题 + 2–3 个精准话题）
#历史 #明朝 #朱元璋 #刘基 #鄱阳湖之战 #大明开局 #历史MV

## 置顶评论（站队题原话 + 作者先答 + 知识卡图）
救，还是不救？换了是你，走哪一条？
我大约会听那八个字。可他要是听了，后来的事就都不一样了。（附图：知识卡.png）

## 合集
大明开局（按集数顺序加入合集）

## 评论区运营（写给自己）
- 发布后 1 小时内回复前 10 条评论；
- 答对“下一集是谁”的评论，置顶或点赞；
- 有人纠错，核对后回复；确实错了，下一集片头用主题栏更正一句。

## 发布前检查
- [ ] 标题、封面、简介、知识卡里的数字和原话都在史实核对表里
- [ ] 系列名、标题、简介没有用原书名或作者名冒充出品方；“讲法参考《明朝那些事儿》”写在简介里
- [ ] 简介和视频里都**不写** Suno、AI 生成之类的字样
- [ ] 发布时在抖音勾选“作品含 AI 生成内容”的声明（平台规则，只勾选，不写进视频和简介）
- [ ] 封面用 cover/cover.png（3:4）；横版封面是第 0 帧 cover/cover-16x9.png
- [ ] 成片 ≤ 100 MB（qa.py 体积一项是 ✓）；右上角署名“@张景行”在视频和 3:4 封面上都有
```

## 写法要点

- **标题**：具体的人、物、数 + 一个悬着的事实；不用“震惊”“竟然”“泪目”“绝了”“神曲”。歌名可以直接当标题之一。
- **封面大字**：手机主页的作品格子很小，两行、每行 ≤ 7 字，第二行朱色。和片子第 0 帧是同一个意思。
- **简介**：前两句用歌词的笔法写钩子（白描、不解释），第三句说明知识卡，最后列出处和“讲法参考《明朝那些事儿》”。
- **话题**：大话题（#历史 #明朝）带量，精准话题（人物、战役）带人群，加系列话题 #大明开局 方便追更。可以加 #历史MV。
- **置顶评论**：片尾卡上站队题的原话 + 作者先答一个有立场、有史实的回答 + 知识卡图。不要求点赞、关注、转发。
- **剧透邀请**：写在简介末尾或置顶评论的第二句（“下一集，下游那个磨桨的人来了。他是谁，懂的人先说。”），必须有明确的史实答案。
