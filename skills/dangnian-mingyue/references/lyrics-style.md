# 歌词写作规范（写歌词前必读）

一集 = 一首歌。歌词的水准对标获诺贝尔文学奖的那位民谣诗人（下文称“那位诗人”）：**具体的人和事、成串的画面、悬而不决的副歌、冷静里带刺**。曲子是陶喆式 R&B 的强化版（见 `suno.md`），所以歌词还要**唱得出来**：主歌可以密、像叙事，副歌要短、留给转音。

## 一、学什么（手法）

学眼光和笔法，不学句子。下面这些手法在那位诗人的叙事歌谣和长诗式歌词里反复出现：

1. **新闻式的叙事歌谣**：有名有姓、有年份、有地名、有数目，像在念一份卷宗。情绪不说，事实摆出来就够了。
   > 城里坐着一个 名义上的皇帝 / 围城的 是张士诚的兵
2. **画面清单（排比）**：同一个起句接一串画面，一句一个，越来越重。
   > 我看见一座城 城门开着却没有人 / 我看见一个老将 倒在自己的旗下 / 我看见三层的船 铁皮像鱼的鳞
3. **悬而不决的副歌**：副歌是一个反复出现的画面或问句，不给答案。每次回来，因为主歌讲的事变了，意思也跟着变。
   > 而江水在涨 江水在涨 / 下游有人 正在磨他的桨
4. **最后一次副歌改一个词**：前面一直唱“江水在涨”，最后一遍改成“江水还在涨”。一个字的变化就是全曲的落点。
5. **第二人称“你”**：对着历史人物说话（“你从哪里来 骑马的人”），像当面质问，又像替他回答。
6. **古今并置**：可以让写字楼、交易所、酒局和 1363 年的围城出现在同一首歌里，让古人的选择照见今天的人。这是那位诗人常用的时代错置手法，**允许用**。但要求是：现代画面要具体（“方案改到第十版”，而不是“内卷”），而且整首歌最多一段，不能抢了历史的戏。
7. **冷幽默和反讽**：用郑重的口气说荒唐的事，不点破。
   > 有人说聪明人 从来不回头 / 有人说肯回头的 才算聪明
8. **预言、经文式的口气**：短句、重复、平实的词，像在宣告。不堆形容词，不用成语凑字。

## 二、不能做

- **不直译、不套用那位诗人的原句和名句句式**，不改写他的歌名。整首歌、歌名、简介里都不出现他的名字，也不写“致敬××”。
- **不写网络词和口号**：破防、内卷、yyds、燃、泪目、热血、宿命、轮回、苍茫、山河、天下大势……这些大词一个都不要。
- **不编细节**：歌词里的每个人名、年份、数目、原话、物件，都要在史实核对表里有出处（见 `fact-check.md`）。拿不准的不写，或者写成“有人说”“号称”。
- **不拿受苦的人开玩笑**：写饥荒、战死、屠城，只写画面，不讽刺。
- **不对观众喊话**：不写“点赞关注”“家人们”。互动放在片尾卡和发布文案里，不进歌词。

## 三、结构与长度

用 Suno 的段落标签写（英文方括号，单独一行）。默认结构如下，可以按章节内容增减：

```
[Intro]                      ← 不写词；前奏越短越好（在风格里写 short intro）
[Verse 1]   6 行             ← 交代：谁、在哪、哪一年、什么局面
[Refrain]   2 行             ← 全曲的钩子：一个画面 + 一个悬着的动作
[Verse 2]   6 行             ← 转折：一句原话、一个选择
[Refrain]   2–3 行
[Bridge]    4 行             ← 可选：古今并置，或者“我看见”清单
[Verse 3]   4–6 行           ← 结果：用一个物件收住
[Final Refrain] 2–4 行       ← 改一个字
[Outro]                      ← 不写词，或者一句轻声的重复
```

- **长度**：正文 30–40 行，唱出来约 3–4 分钟。MV 跟着歌走，不卡时长，但超过 4 分 30 秒，抖音的完播率会掉。
- **每行**：7–14 字，中间用一个空格分成两个短语（“你从哪里来 骑马的人”）。这个空格会变成字幕里的间隔、副歌大字的换行处，Suno 也会在这里换气。一行不超过 15 字，超过就拆成两行。
- **押韵**：押宽韵就行，双句押。副歌可以不押韵，靠重复。不为了押韵换掉具体的词。
- **副歌**：短（每行 ≤ 10 字）、字简单、元音开口（a、ang、ao 结尾的字好拖长音，比如“涨”“桨”“江”），给 R&B 转音留位置。

## 四、可唱性与多音字

- Suno 读中文偶尔会读错多音字，比如“长衫”的“长”、“还”、“重”、“行”、“朝”、“将”。**唱的版本**（`tools/lyrics.txt`）里，有歧义的字换成同音、不歧义的字。**显示版**（`tools/lyrics-display.txt`）保留正确写法。两份文件逐行对应、每行字数相同，`song_sync.py` 会按位置把逐字时间对到显示版上。
- 数字写汉字（“一三六三年”或“那一年”），不写阿拉伯数字。
- 不用生僻字（字体是 GB2312 子集，生僻字会显示成方块；写完跑 `check_glyphs.py`）。
- 英文、拟声词（“oh”“yeah”）最多放在尾奏，主歌和副歌里不放。

## 五、和抖音结构的结合

- **前 3 秒**：前奏期间，画面是标题卡（第 0 帧就是封面），所以第一句歌词要来得早（在风格里写 short intro）。第一句就是钩子：一个具体的人和一个问题。
- **留人**：每段主歌的最后一句都是悬着的，一个没讲完的动作或物件（“然后跨上马 头也没有回”）。
- **转发**：整首歌里放一句**可以原样转述的冷知识**，带数字或反差（“号称六十万 顺流而下”），画面上同时把它印出来。
- **收藏、评论**：知识卡和站队题不进歌词，放在间奏或尾奏的画面里（见 `banhua-style.md`）。

## 六、歌曲说明 `tools/song-brief.md`

写完歌词，同时写一份歌曲说明（生成歌和后面做 MV 都要用）：

```markdown
# 歌曲说明 · 第10集
- 歌名：江水在涨（≤ 6 字；一个画面）
- 一句话：1363 年，朱元璋不听刘基的劝去救安丰，陈友谅趁机顺流而下。
- 曲风：律动叙事（suno.md 模板 A）；BPM 约 80；男声
- 风格提示词（style）：……（≤ 1000 字符，不写任何真实歌手名）
- 避开（negative_style）：……
- 段落：Verse 1 交代 / Refrain 江水 / Verse 2 刘基八个字 / Bridge 古今 / Verse 3 洪都 / Final Refrain
- 古今并置：Bridge（写字楼、交易所）
- 冷知识句：“号称六十万 顺流而下”（《明史·太祖本纪》）
- 多音字替换：长衫 → 唱的版本写“常衫”（显示版写“长衫”）
- 史实细节出处：见交付说明的核对表
```

## 七、自检表（全部 ✓ 才去生成）

| 项 | 标准 |
|---|---|
| 具体 | 每段至少一个人名、地名、年份或数目，都在核对表里 |
| 画面 | 每一行都能画出来（人、物、动作），没有空泛的抒情句 |
| 副歌 | ≤ 2–3 行、每行 ≤ 10 字；最后一次改一个字 |
| 古今并置 | 0 或 1 段，现代画面具体 |
| 禁词 | 网络词、口号式大词、成语堆砌：0 个 |
| 原句 | 没有直译、套用那位诗人的句子；没出现他的名字 |
| 行长 | 7–14 字，中间一个空格；最长不超过 15 字 |
| 多音字 | 唱的版本已替换；显示版和唱的版本逐行、逐字数对齐 |
| 冷知识 | 有一句可转述的，并且带出处 |
| 长度 | 30–40 行，有 [Intro] 和 [Outro] 标签 |
