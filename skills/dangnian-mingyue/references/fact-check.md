# 史实核对

《明朝那些事儿》是通俗历史写法，不少地方和正史有出入。每章都要核对，**以《明史》《元史》等正史和可靠研究为准**，改动全部写进交付说明。

歌词比讲稿更短，每个词都更显眼：**歌词、主题栏、画面上的字、知识卡、发布文案里的每个人名、年份、数目、原话、物件，都要在核对表里有出处**。写歌词前，先从正史和原书里挑出“能入歌的细节”（一句原话、一个物件、一个数目、一个动作），记进核对表；歌词只从这张表里取细节，不编。

## 流程

1. 读完章节后列一张清单：人名（含本名/庙号/年龄）、地名（古今对照）、年份（公元 + 年号）、关键事件、原书引用的史料出处。
2. 对每一项查原文：
   ```sh
   python3 -I scripts/wikisource.py search '"五姓漢人" 元史'      # 不知道在哪一卷时先搜：繁体、原文短语加引号、带上书名
   python3 -I scripts/wikisource.py page "明史/卷1" 至正四年       # 取一卷，只看关键词上下文（繁简同形的词直接搜）
   ```
   搜索结果里常混有演义、小说（《元史演义》《英烈传》《明史演义》等），**不能当依据**，只用正史、实录、当时人的笔记文集和学术研究。
   维基文库会限速（429），脚本自带退避重试；卷名不统一（“元史/卷38”可能不存在），先用 search 找到正确的页名。也可用网络搜索找学术考证。
3. 判定：
   - 与正史一致 → 照讲，可在屏幕上标出处（“《明史·太祖本纪》”）。
   - 原书有误 → **歌词按正史改**，交付说明里记一行。
   - 正史本身就是传说、谶语、孤证 → 屏幕上标“据载”“传说”“相传”。
   - 查不到可靠出处 → 不讲，或明确说“这只是一种说法”。

## 第一章已经核对过的要点（可直接复用）

- 1328 年（元天历元年）九月生于濠州钟离；《明史·太祖本纪》：“及产，红光满室……邻里望见，惊以为火，辄奔救，至则无有。”朱家“生四子，太祖其季也”。
- 祖上数字名（朱百六、朱四九、朱初一、朱五四）见朱元璋所撰碑文；“元朝不许平民取名、只能用父母年龄相加”之说**无史料依据**（洪金富《数目字人名说》，史语所集刊第 58 本，1987）。
- “放牛十二年”无据；正史只记“田主刘德”（《御制皇陵碑》）。
- 1328–1333 年：泰定帝 → 天顺帝（9 岁虚岁，在位一个多月）→ 文宗图帖睦尔（是泰定帝的堂侄、天顺帝的堂兄，不是“堂叔”）→ 明宗（文宗亲兄，见面数日后暴卒，多疑毒杀）→ 文宗复位 → 宁宗（7 岁虚岁）→ 顺帝（文宗即他的叔父，曾将他迁往高丽大青岛、静江；元人称惠宗）。
- 官吏勒索名目出自叶子奇《草木子》：“所属始参曰拜见钱，无事白要曰撒花钱，逢节曰追节钱，生辰曰生日钱……论诉曰公事钱”——是勒索，不是国家税目；“追节钱”不是“过节钱”。
- “悉空其人以为牧地”是蒙古太宗朝近臣别迭等的提议，被耶律楚材以“岁可得银五十万两、帛八万匹、粟四十余万石”劝止（《元史·耶律楚材传》），不在元末。
- 1337 年（至元三年）伯颜请杀张、王、刘、李、赵五姓汉人，帝不从（《元史·顺帝纪》）。
- 1344 年（至正四年）：“旱蝗，大饥疫，太祖时年十七”（《明史》）；五月黄河北决白茅堤（《元史·河渠志》）。
- “石人一只眼，挑动黄河天下反”是 1351 年（至正十一年）贾鲁治河时于黄陵冈掘出（据元末明初记载），不是 1344 年。颍州刘福通 1351 年起事，濠州郭子兴 1352 年起事。

## 常见陷阱

- **年龄**：古籍多用虚岁。片中标“（虚岁）”，或换算成周岁并说明。
- **人名用字**：庙号、年号、本名不要混；字体缺字时用庙号。
- **亲属关系**：原书常把辈分说错，查世系再写。
- **年号与公元**：年号年和公元年不完全重合（年初年末跨年），写“1328 年（天历元年）”即可，不要硬换算到月日。
- **地名**：古今对照用“今 ××”，以通行说法为准；地图位置是示意，屏幕上可注“地图为示意”。
- **数字**：书中的“几十万大军”多为虚数，史书有记载就用记载，没有就说“号称”。
- **古今并置**：歌词里写现代画面（写字楼、交易所）是修辞，不算史实；但同一句里提到的古人、古事仍然要准确。
- **歌被唱错**：Suno 偶尔会改字、漏字。以对齐结果（实际唱的）为准核对；唱错了史实（比如年份），在交付说明里写明，必要时请用户决定要不要重新生成。
