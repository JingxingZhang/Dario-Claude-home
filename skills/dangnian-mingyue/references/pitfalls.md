# 避坑清单（做样张和示例片时踩过、修过的）

## 歌（Suno）

- **只生成一次**：免费版每月 50 credits。生成前先过 `lyrics-style.md` 的自检表，歌词定稿再调用；不要“先生成一首听听”。
- **不调用 audio-download**：下载额度是 0。让用户在网页上下载。
- **歌没 complete 就让用户下载**：网页上会下不了或只下到一半。先 `audio-wait until: "complete"`，再发链接。
- **对齐数据要原样存**：`audio-lyrics-alignment`、`audio-analysis` 返回的 JSON 原样写进 `tools/`，不要手改、不要摘要。`song_sync.py` 只认原样。
- **对齐和分析一开始是 processing**：第一次调用只是启动，隔几秒再调用；分析的节拍、段落、描述是分开出的，`status` 离开 `processing` 才算完。
- **`bar_position` 不可靠**：只用节拍时间点；不要按“小节第一拍”切镜头。
- **mp3 对不上**：`song_sync.py` 报时长差 > 0.5 秒，多半是用户下了另一版（Suno 可能一次出两首），或者下载时被截断。问清是哪一首，不要用 `--force` 硬过。
- **多音字**：唱的版本（lyrics.txt）和显示版（lyrics-display.txt）必须逐行、每行字数相同；不同的话，`song_sync.py` 会退回用唱的版本当字幕（字幕上就会出现同音字）。

## 画面（引擎）

- **人物、器物的 (x, y) 是“水平中心、着地线”**，不是左上角。做样张时把马的 y 当成了左上角，马整个画到了画面外面。
- **第一个镜头必须从 0 秒开始**，否则 `F.finish()` 报错。第 0 帧就是横版封面，首帧元素不做淡入。
- **`box` 要包住整个形体**：版只印 box 里的东西，box 小了会被切掉；box 太大则印得慢、占内存。会移动的元素，box 包住它“原位”就行，移动用 `x/y`。
- **遮挡**：前面的元素要挡住后面的，就得 `o.knock(轮廓)`（场景库里的人、物都已经 knock 了）。自己画的剪影忘了 knock，后面的天空刻线会从剪影的白刻线里透出来。
- **一块版里的“挖洞”用 `BH.erase`**（比如窗外露出天），`o.knock` 是“挡住别的版”，两件事别混。
- **同一块版里画两扇窗的天**：先 `clip` 到窗框再画天；不要“画满再擦掉窗外”，第二扇窗的擦除会把第一扇的天擦掉（示例片就踩过）。
- **朱色字写在朱色块上**看不见：要“红底纸色字”，就画朱块，再用 `BH.erase(o.red, c => BH.text(c, …))` 把字挖出来（纸色就露出来了）。
- **字幕带里别放东西**：y 890 以下是字幕带，人物着地线放在 860–880。`check.js` 会报“撞到字幕带”（宽的地面条、背景不报）。
- **推镜要设 res**：推到 1.3 倍时 `res` 也设到 1.3 左右，否则会糊。
- **sh.type 的时间**：传句号（`sh.type(7)`）才能按逐字时间砸字；传字符串时，字按镜头开始后每 0.12 秒一个出来。
- **副歌大字自动折行**：按空格分短语，超过 4 个字再均分；要别的断法就传 `rows: ['汉吴', '伺隙']`。
- **主题栏换段的时间**：`F.topic(S.sec(n).start, …)` 是在那一段的第一个字时换。副歌镜头若提前 0.25 秒切进来，会有 0.25 秒还是上一段的主题栏；介意就把 topic 的时间也提前。

## 渲染与检查

- **长任务放后台**：整片渲染约 20 分钟（4 分钟的歌）。前台命令最长 10 分钟，用 `run_in_background`，并告诉用户大概要多久。
- **先看小样**：`render.js --from 30 --to 45 --draft` 只渲染一段，确认节奏和转场，再渲染整片。
- **音轨**：`render.js` 要 `assets/song.wav`（`song_sync.py` 生成）；测试用 `--silent`。
- **体积**：纸纹颗粒让码率很高，10 秒 CRF 18 约 15 MB；整片靠码率封顶压在 100 MB 内，画质够用。要更小就 `--max-mb 60`。
- **检查**：`check.js` 每 0.5 秒采样一次（约 30–60 秒），✗ 必须修，⚠ 导出那一刻看一眼再判断。

## 环境（4 核 CPU 实测）

| 步骤 | 耗时 |
|---|---|
| setup.sh 首次（下载、裁剪字体） | 约 4 分钟 |
| song_sync.py | 几秒 |
| check.js | 30–60 秒 |
| 一批关键帧（still.js，17 张） | 约 25 秒 |
| render.js（逐帧 + 编码） | 约为片长 × 6（一首 4 分钟的歌约 20–25 分钟） |

- 云端会话结束后容器会清空：成片和工程要在结束前发给用户，或者打包。
