# 过去做过的三张表情包（只作参考）

都是《呼吸决定》MV 发布后，为评论区互动做的：
- `emoji.py`：关注领原视频（粉色；礼盒 + “+关注”按钮）
- `emoji2.py`：感谢关注、求推荐（橙色；笑脸大心 + “推荐”按钮 + 烟花）
- `emoji3.py`：关注后优先定制下一首（蓝紫；复古点歌机吐出“优先券”）

新歌不要套用这几张，按歌词和 MV 里的角色、道具现做。通用部件已经收进 `lib/sticker.py`，起手用 `templates/sticker_template.py`。
这三个文件是当时的原样代码，导入路径指向旧项目，直接运行会报错，只看写法即可。
