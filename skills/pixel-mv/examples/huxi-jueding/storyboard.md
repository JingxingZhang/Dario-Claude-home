# 呼吸决定 · 像素 MV 第二版（原唱：Fine乐团）

这一版的改动：画面里的像素部分也做成综艺节目的样子，不再只有底部歌词是花字。
- **像素花字**：拟声词（叮！啪！嗝~ 咔嚓 扑通 卡！）、印章（第一天、警报、假、翻车、坦白局、封存、回忆杀、清醒）、内心 OS 气泡、对话气泡、系统消息（对方已离开）、复古弹窗（确定离开吗？[是][否]）、数值条（渣男指数、测谎仪、恋爱进度、表白加载中、BPM）、开关（恋爱模式 ON、感情 OFF）、回放段弹幕。
- **配角会演戏**：橘猫全程跟着吐槽（举牌、哈气、捂眼、戴警帽、戴墨镜走秀、坐电驴戴风镜、打滚冒心）；月亮、路灯、垃圾桶、闹钟、日历、手机、心、楼房都有表情。
