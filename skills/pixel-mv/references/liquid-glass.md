# 液态玻璃层（Liquid Glass 风格）：设计与用法

本 skill 的画面分两层：
- **像素层（世界）**：320×180 原生像素画，最近邻放大到 1080p。人物、场景、道具、像素综艺花字都在这一层。
- **液态玻璃层（界面、文字、念头）**：直接画在 1080p 高清帧上，会折射底下的像素世界。

两层的反差（粗粝的像素 + 细腻通透的玻璃）就是这套风格的质感来源。玻璃效果参照 Apple 在 WWDC25 发布的 Liquid Glass 设计语言，抓三个要点：
1. **折射，而不只是模糊**：玻璃边缘的斜面把背景“折”进来，背景的线条在边缘弯曲，中间略微放大。
2. **会游走的镜面高光**：沿着曲边有一道细亮线，随时间慢慢移动，玻璃才像玻璃，不像一层彩色贴膜。
3. **液体般的形变**：出现时先横向拉开、再纵向回弹；移动时会被拉长；两块靠近时可以融在一起。

实现见 `lib/glass.py`（numpy + PIL，不需要 GPU）和 `lib/glassui.py`（组件）。引擎默认开启，`MV(..., glass=False)` 可以关掉，变回纯像素版。

## 引擎自动加的
- 整帧轻柔光 + 暗角（`post_fx`）；
- **歌词底部玻璃托盘**（`lyric_dock`）：随每句歌词弹出、收起；
- **署名玻璃胶囊**；
- **段落透镜横扫**：在 `MV(..., sections=[秒, …])` 列出的时刻，一颗大玻璃透镜从左到右扫过画面，通常放在主歌、副歌、间奏、桥段、尾奏的起点。

## 镜头里可用的组件（`from glassui import *`）
坐标默认是原生坐标（320×180），born 是出现时刻（全片秒，常写 `t - lt + 镜头内秒`），born=None 表示常驻。

| 组件 | 用途 | 例子 |
|---|---|---|
| `gchip(t, born, cx, cy, text, col, size)` | 玻璃胶囊标签 | 定性词、页码、小字幕 |
| `gtag(t, born, cx, cy, text, pal)` | 按配色名着色的标签 | “说词”“慷慨”“自私” |
| `say(img, x, y, s, t, born, tail)` | 对话气泡：打字时胶囊变长，尾巴是一颗小水滴 | 替代 props2.say |
| `OS(img, x, y, s, t, born)` | 内心 OS：深色玻璃气泡 | 心里话 |
| `popup(img, x, y, title, msg, btns, born=…)` | 玻璃提示卡 | “查无此词” |
| `meter(img, x, y, label, v, col)` | 玻璃胶囊里一段会涨的液体 | 真实度、心动值 |
| `gsearch(t, born, cx, cy, hw, query, result)` | 玻璃搜索框 | 搜“你” |
| `gcard(t, born, cx, cy, hw, hh, r, content=…, sdf=…)` | 任意玻璃卡片 / 形状 | 名字牌、玻璃管、分隔条、窗玻璃 |
| `gheart(t, born, cx, cy, size)` | 心形玻璃窗 | 心里装着谁 |
| `glens(t, cx, cy, r)` | 圆形透镜：放在物件上会把它放大 | 镜子、放大某个细节 |
| `gdrop(t, born, cx, cy)` | 溅起一颗玻璃水珠 | 落叶着地、按下按钮、心跳 |
| `bubbles(t, n, seed, …)` | 缓缓上浮的玻璃水滴 | 前奏、梦境、尾奏的氛围 |
| `gmove(t, born, a, b)` | 液态选择框：从 a 流到 b，移动中被拉长 | 选择题、高亮一个词、切换选项 |
| `gsign(cx, cy, text)` | 配角举的牌 → 头顶一枚玻璃小牌 | 宠物、物件吐槽 |

更底层的 `glass(big, cx, cy, hw, hh, sdf, …)` 可以画任意形状：`sdf_rrect`（圆角矩形 / 胶囊）、`sdf_circle`、`sdf_heart`，以及 `sdf_union`（平滑并集，两块玻璃融成一体）。

## 动效（让玻璃像液体一样顺滑）
- **弹簧**：Apple 式阻尼弹簧，起步速度为 0、过冲约 8%、约 0.5 秒稳定（`glass.spring(dt, response=0.42, damping=0.78)`）。
- **出现**：带 born 的组件从 55% 大小弹开，横向先、纵向晚 0.05 秒，同时 0.18 秒淡入；一道高光沿边缘扫过。
- **待机**：轻微上下浮动（约 2 像素）。
- **退场**：镜头结束前 0.26 秒自动收缩、淡出、微微上飘（引擎写入 `glassui.SHOT`）；需要提前退场就传 `dur`。不会在切镜头时突然消失。
- **气泡**：打字时胶囊宽度平滑地跟着变长；尾巴是一颗小水滴，先和气泡连在一起，再“拉丝”分离出来（距离场平滑并集）。
- **选择框**（`gmove`）：移动时横向拉长、纵向略压扁，停下时回弹。
- **歌词托盘**：相邻两句间隔小于 0.9 秒时，托盘从上一句的形状连续变形到下一句；间隔长才收起、再弹出。
- **段落透镜**：两端慢、中间快，移动时沿方向拉长成椭圆。
- **帧率**：`render.py --fps 60` 让所有动效更顺滑，渲染时间约翻倍；默认 30。
- `born=None` 的是结构性玻璃（窗、镜面、玻璃管、分隔条），常驻、不做动画。

## 设计原则
- **玻璃承载“词”和“界面”，像素承载“世界”**：标签、气泡、弹窗、数值条、选择框、搜索框、名字牌用玻璃；人物、风景、物件、拟声词和印章仍然是像素。镜子、窗户、水面这些本来就是玻璃或水的东西，也可以叠一层玻璃。
- **克制**：同一屏除了歌词托盘和署名，玻璃元素最好不超过 3 个。玻璃太多会糊成一片，也抢了像素世界的戏。
- **让玻璃和故事有关**：玻璃最好是故事里的东西，比如主角脑子里的念头、对话、屏幕。纯装饰的水滴只放在前奏、尾奏、梦境这类氛围段落。
- **折射要有东西可折**：玻璃底下最好有线条、边缘或亮色（树冠、窗格、横线、太阳），折射才看得出来；放在大片纯色上就只剩一圈高光。
- **字看得清**：玻璃会根据底下的亮度自动选深色或浅色字（浅色字带细描边）。别把玻璃放在太阳、强光源正上方，底色太亮太花时，调大 `tint_a`（0.2–0.4）让玻璃更“磨砂”。
- **遮挡**：玻璃也不能压住人物的脸和底部歌词，原生 y<120 的规矩同样适用。
- **动效节奏**：组件出现时自带弹簧回弹（约 0.4 秒），born 最好踩在拍点或重点词开唱的那一刻。

## 性能
每帧多花约 0.3–0.5 秒，4 进程渲染一首 3–4 分钟的歌大约 10–15 分钟（纯像素版 3–4 分钟）。开工时告诉用户预计时长；改动小样用 `render.py --from --to --draft`。
