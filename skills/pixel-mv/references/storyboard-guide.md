# 分镜方法（写分镜前必读；先完成 故事.md 和 visual-design.md 的视觉方案）

目标：观众看任何一秒，都能从画面上“读出”正在唱的那句词，同时知道故事走到了哪一步，还觉得好玩。
做法是 **剧情节拍 + 字面意思 + 综艺梗**：先确定这句在故事里发生了什么，再把这句词里能画的人、物、动作画出来，最后加一层综艺式的放大或吐槽。

## 1. 先读懂歌、读懂故事
- **先看「创作背景与主题」、`歌词精读.md` 和 `故事.md`**：每句的意思以精读为准，每句在故事里的位置以节拍表为准。
- 谁对谁说？一句话讲完这个故事：处境 → 选择 → 结局。
- 段落时间：前奏、主歌、副歌、间奏、桥段、尾奏（看 lyrics.txt 的间隔和 audio.json 的音量），并写出 `SECTIONS`（段落切换时刻，用于透镜转场）。

## 2. 定角色和贯穿物件（详见 visual-design.md）
- **主角从零设计**：人数、年龄、时代、穿着，甚至是不是人，都从歌词和故事里找答案；用 `charkit.pixmap` 逐像素画，比例按曲风定。
  - 不要默认“一个女生 + 一个男生”。`chars.person` 那套 Q 版小人只用于试画和路人群演。
- **贯穿配角或物件，选一个用到底**，并给它一条成长线（开头 → 中段 → 结尾），跟着故事变。
- **会演戏的物件**：优先让歌词里出现的东西演戏，在关键句做反应。
- 设定图 `CAST_SHEET` 和故事、分镜一起交给用户确认。

## 3. 逐句设计：每句写满 6 格
先把这句在 `故事.md` 节拍表里的位置、`歌词精读.md` 里的 ②意象、③双关、④潜台词、⑥可画的画面点读一遍，再填：
| 格 | 问自己 |
|---|---|
| 剧情节拍 | 这句在故事里发生了什么？和上一句相比，故事往前走了哪一步？ |
| 场景 | 这句发生在哪？歌词提到地点就用；没提就选故事需要、又能放大这句情绪的地方（审讯室=逼问，天台=告白，片场=演戏） |
| 人物 | 谁在做什么动作、什么表情？把动词画出来（“挥着旗”就真挥旗，“缩着手”就真缩） |
| 像素字与玻璃元素 | 拟声词、印章用像素；标签、对话、OS、弹窗、数值条、选择框、搜索框用玻璃（见 liquid-glass.md） |
| 配角/物件 | 贯穿配角怎么吐槽或陪伴？它的成长线走到了哪一步？哪个物件该有反应？ |
| 对应关系 | 一句话说明为什么贴这句词，引用精读里的意象或潜台词，以及故事节拍；说不出来就重想 |

### 歌词意思 → 画面的转换手法
- **数量和时间**（“两天”“一整天”）→ 日历翻页、液体进度条、钟表、太阳移动、季节更替。
- **抽象情绪**（“情绪决定”“心动”）→ 仪表、老虎机、开关、心电波形、玻璃管里的水位。
- **真假、演戏**→ 测谎仪、面具掉落、片场打板“卡！”、评分牌。
- **离开、结束**→ 系统消息“对方已离开”、玻璃提示卡“确定离开吗？”、背影越走越远、路灯变暗。
- **记住、在乎**→ 对话气泡飞进心里、心形玻璃窗里装着某样东西、“已保存”。
- **逼问、坦白**→ 审讯灯、清单一条条“叮”出来。
- **选择、犹豫**→ 玻璃选择框在选项之间流动（`gmove`），最后停在答案上。
- **告白、喜欢**→ 喇叭喊话、整栋楼的窗户亮成心、烟花、捂脸“///”。
- **反转**→ 先给一个正常画面，再用通知、印章、弹窗“翻车”。

### 节奏
- 一句通常一个镜头。句子长于 5 秒就安排 2–3 个动作点（例如第 0.3 秒弹出、第 1.6 秒翻页、第 2.4 秒盖章），让画面一直在变。
- 动作点和玻璃元素的出现时刻尽量踩在字上或拍上：重点词开唱的那一刻出印章、标签或气泡。
- 同一屏最多 3 处字：歌词花字 + 1–2 个像素字或玻璃标签。太挤就删。

## 4. 结构规则
- **前奏**：0 秒就是标题卡（引擎叠加歌名和原唱），背后的画面要在动，交代故事的开场状态；之后用 2–3 个镜头交代主角是谁、在哪、和贯穿配角的关系，最好埋一个后面会用到的道具。
- **间奏**：故事的时间流逝或转场：蒙太奇、季节变化、在路上；贯穿配角在这里给温度。
- **重复段（第二遍主歌、每一遍副歌）**：按 `故事.md` 的“重复歌词的新含义”表画**新镜头**：
  - 可以沿用同一个构图、同一个地点做“视觉押韵”，让观众认出这句；
  - 但人物状态、时间、天气、道具或结果一定要变，并且这个变化就是故事的推进；
  - 不再使用回放、弹幕、复用镜头换配色这类做法。`sweep.py` 会把重复使用的镜头函数报成错误。
- **桥段**：故事的转折，可以换一种画面语言（剪影、黑白、梦境、玻璃气泡里的想象）。
- **全曲最后一句**：故事的结局，顺着它（尤其是被改动的字）走。
- **尾奏**：结局之后的余韵，最好和开场首尾呼应（同一个地方，人已经变了）。
- **片尾**（`end_start` 起）：引擎显示歌名、原唱、“谢谢收看”；画面放故事的最后一个安静画面，可以让配角举“谢谢收看”的玻璃小牌。

## 5. 自编内容
画面里的名字、聊天内容、梗、补出来的情节都是自编的，要在 `故事.md` 和分镜表的“自编”一节列出，请用户确认。不碰真人，不写低俗内容，不给“我”“你”编真实姓名。

## 范例
`examples/huxi-jueding/`（mv.py + storyboard.md）：《呼吸决定》全片 38 句，可以学它的逐句写法、反转和物件演戏。
但它是旧流程：重复段用了回放和复用镜头，也没有故事节拍和玻璃层，这几处不要学。
