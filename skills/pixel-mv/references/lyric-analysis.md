# 逐句歌词精读（写分镜前必读）

查到歌名、作者和创作背景，只能知道这首歌**大致讲什么**。真正决定画面的是每一句词：同一个主题下，每句都有自己的意象、潜台词和情绪位置，很多句子能读出好几层意思。分镜要从这些意思里长出来，不能只拿主题套模板，更不能从单个字眼联想剧情。

精读写进项目里的 `歌词精读.md`（模板：`templates/lyric_analysis_template.md`），在检查点和分镜说明一起交给用户。

## 0. 先通读，再逐句
1. 把 `tools/lyrics.txt` 从头到尾读两遍，先不看单句，回答：
   - 说话的人是谁、对谁说、在什么时间和地点说；
   - 两人的关系处在哪个阶段（暗恋、暧昧、热恋、分手后、回忆……），整首歌有没有变化；
   - 情绪曲线：从哪里开始，在哪一句转折，停在哪里。
2. 标出**重复段**（第二遍主歌、每遍副歌），以及**重复时被改动的字**。改动的地方往往就是全曲的落点。
   - 例：《晚安》每遍副歌都落在「多情人**却自找**难堪」，最后一句改成「多情的人**始终**难堪」。从“自找”到“始终”，是从自嘲变成认命。
3. 再对照第 1.5 步查到的主题，确认通读的结论和主题一致；不一致就回头检查，是背景查错了，还是理解偏了。

## 1. 每句拆六层
每一句（重复句只精读第一次，后面写“同第 N 句，变化：……”）都写满下面六项：

| 层 | 要回答的问题 |
|---|---|
| ① 字面 | 这句话直译是什么意思？有没有生僻词、方言、网络用语、古语？ |
| ② 意象 | 句子里有哪些能画出来的东西（月色、窗、桥、毛线、手机、夜）？分别象征什么？ |
| ③ 修辞与双关 | 比喻、拟人、对比、夸张、双关、倒装、反语？一个词能不能读出两层意思？（例：「烂桥段」既是老套的剧情桥段，也能画成一座烂掉的桥） |
| ④ 潜台词 | 没说出口的是什么？说话人真正的心情和动机？是自嘲、抱怨、试探、口是心非，还是在说服自己？ |
| ⑤ 在全曲的位置 | 这句在情绪曲线上处于哪里（铺垫、加深、转折、高潮、回落）？和上一句、下一句是什么关系（因果、对比、递进）？ |
| ⑥ 可画的画面点 | 由前五层得出：这句最该画出来的是哪个意象、哪个动作、哪种情绪？有没有能做综艺梗的点？哪种画法会**违背**本句意思（要避开）？ |

## 2. 有歧义的词，单独列出来
- 一个词能读出两种以上意思，或者会直接影响人设和关系的（“多情人”“见异思迁”“几人份”），要单独列一张表：可能的解读 → 采用哪种 → 依据（主题、上下文、创作背景、主流听众解读）。
- **默认采用最贴主题、最贴上下文的解读**；拿不准就在检查点请用户定。
- 反例（《晚安》踩过的坑）：
  - 「多情人却自找难堪」：把“多情人”读成“花心的你”，结局就会改成让对方难堪。按上下文，“自找”难堪的是一直放不下的“我”，“多情”是动了真情。
  - 「几人份的畅谈」：读成“同时跟好几个人聊”，就编出了“群发晚安”。按主题（暧昧），它是两个人聊得太多，多到像几个人的量。
  - 「见异思迁」：在暧昧的语境里是心思忽冷忽热、说变就变，不必画成“换人”。

## 3. 写法要求
- 只精读用户提供的歌词（`tools/lyrics.txt`），不凭记忆补词、改词。
- 引用听众解读或乐评时注明来源；自己的理解写“我的理解”，不要写成定论。
- 每句的 ⑥ 必须能在分镜表里找到对应：分镜表最后一格“为什么贴这句”要引用精读里的意象或潜台词。说不出对应关系，就是在套模板。
- 写完再通读一遍精读：人物是否前后一致？关系有没有在中途被写歪？结尾的处理是否贴最后一句（尤其是重复时被改动的那几个字）？

## 4. 精读怎么影响后面（下一步是写故事，见 story-design.md）
- **人设**：从 ④ 潜台词和关系阶段来（谁更投入、谁在退、两人是否都在动心），不要从单个形容词来。
- **贯穿道具**：优先选在多句 ② 里反复出现的意象，或者最能概括主题的那个（《晚安》：关系进度条“朋友——恋人”，滑块卡在暧昧区）。
- **节奏**：⑤ 标为“转折”“高潮”的句子安排更多动作点和更强的花字。
- **自编梗**：只能放大 ③④ 里已经有的意思，不能新造歌词里没有的剧情（比如“对方花心”）。
- **结局**：看最后一句和它被改动的字，结局只能顺着它走，不能反着改。
- **故事**：精读的结论是写 `故事.md` 的原料：人设和关系定人物，潜台词定动机，转折句定故事的转折点，重复句前后语境的变化定“同词不同义”的推进方式。
