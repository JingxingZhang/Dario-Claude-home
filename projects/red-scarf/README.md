# The Long Red Scarf（长长的红围巾）— 30 秒 AI 动画短片

参考片的**风格与结构**（2D 手绘绘本质感、一镜一梗的默片喜剧、重复后翻转），但角色、道具、场景、结局都是原创的。

## 故事（30s，13 个镜头）

大风的深秋海边坡城。一个高瘦、永远一脸困意的红发女孩，脖子上绕着一条几米长的红围巾，腋下夹着法棍，一路走一路用围巾顺手帮了所有人：卷回气球、扫回报纸、绑住要倒的梯子、兜住鸟窝、托住茶杯。后来她用围巾去勾挂在树上的风筝，围巾跟着风筝飞上了天。风停了，第一片雪落在她鼻尖上，她冷得一抖。这时红围巾从天上飘下来，正好绕回她的脖子。

## 模型选择（2026-11 查询，价格以 Google 官方页为准）

| 模型 | 1080p 单价 | 用在哪 |

| **Veo 3.1 Fast** | ~$0.12/s | **主力**：13 个镜头的图生视频全部先用它 |

预算估算：13 镜 × 4s × 平均 4 次 × $0.12 ≈ **$25**（Veo 部分；Nano Banana 出图另计）。全用 Quality 约 $83。

## 剪辑工具

```bash
python3 tools/build_edit.py            # 1080p 成片 -> out/red_scarf.mp4
python3 tools/build_edit.py --preview  # 540p 快速预览
python3 tools/review_sheet.py clips/S05_t2.mp4   # 单条片段接触表，用来挑入点
```

每个镜头按这个顺序找素材：`clips/SXX.mp4` → `stills/SXX.png`（静帧推镜）→ 灰色占位卡。所以素材到一部分就能先出一版预览。
